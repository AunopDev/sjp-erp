---

## 1. ปัญหาก่อนปรับ

- **ซ้ำซ้อน**: รายการโปรด + รายการล่าสุด + กลุ่มเมนู แสดงรายการเดียวกันหลายรอบ
- **ค่าเริ่มต้นรก**: ระบบปักหมุดหน้าแรก/แจ้งซ่อม/โครงการให้อัตโนมัติตั้งแต่แรก
- **ดาวปักหมุดทุกแถว**: ดาวสีเทา/เหลืองโผล่ตลอด แย่งความสนใจจากเมนู
- **หลายกลุ่มเปิดพร้อมกัน**: sidebar ยาวและเลื่อนยาก
- **footer ซ้ำ**: ปุ่มโหมดมืดซ้ำกับ user menu
- **drawer มือถือ**: quick create chips ซ้ำกับปุ่ม Quick Create บน topbar
- **ไม่รู้ว่าอยู่กลุ่มไหน**: group header ไม่มีสถานะ active

---

## 2. สิ่งที่เปลี่ยน

### 2.1 ลดจำนวน section
- เอา **“ล่าสุด”** ออกทั้งหมด
- **รายการโปรด** แสดงเฉพาะเมื่อผู้ใช้ปักหมุดจริง (ค่าเริ่มต้นว่าง)
- ลบ drag hint “ลากเพื่อจัดลำดับ” ออกจากหัว section

### 2.2 Accordion เปิดทีละกลุ่ม
- เปิดกลุ่มใหม่ = ปิดกลุ่มอื่นอัตโนมัติ
- เมื่อ navigate ไปหน้าใด ระบบเปิดกลุ่มของหน้านั้นและปิดที่เหลือ
- ค่าเริ่มต้นเปิดเฉพาะ “ภาพรวม”
- การค้นหาจะแสดงผลทุกกลุ่มโดยไม่สนสถานะเปิด/ปิด

### 2.3 ปักหมุดแบบเงียบ
- ดาวปักหมุดซ่อนไว้จนกว่า row จะ hover/focus
- รายการที่ปักหมุดแล้วจะแสดงดาวตลอด
- บนอุปกรณ์ touch แสดงดาวจาง ๆ เพื่อให้แตะได้

### 2.4 ลด chrome
- เอา footer “โหมดมืด” ออกจาก sidebar ที่ขยายแล้ว (ใช้ user menu แทน)
- rail mode ยังมีปุ่ม theme/ขยายเมนูแบบ icon-only
- เอา quick create chips ออกจาก drawer มือถือ (topbar มีปุ่มอยู่แล้ว)
- group header ของกลุ่มที่ active มีสีเข้มขึ้นและไอคอนสีแบรนด์

---

## 3. พฤติกรรมที่ได้

- เปิดหน้าแรก → เห็นเฉพาะกลุ่ม “ภาพรวม” ที่เปิดอยู่
- ไปหน้าแจ้งซ่อม → กลุ่ม “งานบริการและโครงการ” เปิด กลุ่มอื่นปิด
- ผู้ใช้กดกลุ่มอื่น → กลุ่มนั้นเปิด กลุ่มเดิมปิด
- ผู้ใช้ hover เมนู → เห็นดาวปักหมุด, กดเพื่อปักหมุด
- ปักหมุดแล้ว → มี section “รายการโปรด” ด้านบน และดาวติดค้าง
- มือถือ → เปิด drawer เห็น search + กลุ่มเมนูแบบเปิดทีละกลุ่ม ไม่มี chips ซ้ำ
- ไม่มี favorites → bottom nav ใช้ 3 เมนูแรกอัตโนมัติ
